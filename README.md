# ghalvera.github.io

The published public surface for **Ghalvera**, an independent security
research laboratory studying whether a record can be trusted — and whether
you would know if it couldn't.

This repository is a **publication surface, not a source of truth.** The site
is authored in the private `ghalvera` laboratory repository, under
`web/ghalvera.com/`, alongside the range harness, the ledger and the run
evidence. Only the files needed to serve the site are copied here.

Edit the private repository, then re-copy. An edit made directly here will be
overwritten and will not reach the real source.

No custom domain is configured. `ghalvera.com` is not registered; if it is
later, add a `CNAME` file here and point DNS at GitHub Pages — no other change
is required.
