# ghalvera.github.io

The published public surface for **Ghalvera**, an independent security
research laboratory studying evidentiary sufficiency under valid verification:
whether a genuine security record is enough for the exact conclusion attached
to it.

This repository is a **publication surface, not a source of truth.** The site
is authored in the private `ghalvera` laboratory repository under
`web/ghalvera.com/`, alongside the research programme and its instruments.
Only files needed to serve the site are copied here.

Edit and independently review the private repository, then re-copy and verify
byte parity. An edit made directly here will be overwritten and will not reach
the canonical source.

The public site presents a working hypothesis, not an earned Foundation
designation. Its candidate frontiers are not active projects, and offensive
work is restricted to owned or explicitly authorized environments.

No custom domain is configured. `ghalvera.com` is not registered; if it is
later, add a `CNAME` file here and point DNS at GitHub Pages — no other change
is required.
